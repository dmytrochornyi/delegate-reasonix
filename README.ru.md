# delegate-reasonix

[English version](README.md)

Скилл для [Claude Code](https://claude.com/claude-code), который делит работу между двумя агентами:
**Claude планирует и проверяет, [Reasonix](https://github.com/esengine/DeepSeek-Reasonix) (агент на DeepSeek)
пишет код.** Claude думает, Reasonix делает основную реализацию, и на больших задачах это экономит
токены Claude.

## Как работает

Скилл запускается командой `/delegate-reasonix <задача>` или сам, после того как ты одобрил план.
Дальше Claude:

1. **Изучает репозиторий**: состояние git, файлы и тесты, которые затронет задача, команду сборки и
   тестов. Если есть незакоммиченная работа, которую Reasonix может перезаписать, предупреждает.
2. **Составляет задание**: твоя задача дословно, нужные файлы и ограничения. Reasonix трогает только то,
   что нужно для задачи, запускает тесты и сам коммитит свои изменения (только свои файлы, без push,
   amend, rebase и reset).
3. **Фиксирует исходное состояние и запускает Reasonix** без интерфейса:
   `reasonix run --model deepseek-pro --dir "$PWD" --yolo "<задание>" < /dev/null`.
   Перед этим рабочая копия должна быть чистой: Claude предложит контрольный коммит, потому что в
   режиме yolo нет подтверждений. Если у репозитория есть remote, Claude спросит перед запуском.
4. **Проверяет результат**, не веря отчёту Reasonix: новые коммиты, diff, не переписана ли история,
   не осталось ли незакоммиченных файлов, запускались ли тесты. Если нет, запускает их сам.
5. **Отчитывается**: коммиты, изменённые файлы, результаты тестов, замечания. Сам ничего не откатывает
   и не пушит. Если что-то сломалось, предлагает `git reset --hard <head_before>`, а решаешь ты.

Если есть одобренный план, скилл отдаёт Reasonix по одной фазе и проверяет каждую перед следующей.

## Требования

- Claude Code
- установленный Reasonix CLI с твоим ключом DeepSeek API (ключ хранится в настройках самого Reasonix,
  скилл его не трогает)
- git-репозиторий, в котором идёт работа

## Установка

```bash
git clone https://github.com/dmytrochornyi/delegate-reasonix.git
mkdir -p ~/.claude/skills
cp -r delegate-reasonix/skills/delegate-reasonix ~/.claude/skills/
```

Перезапусти Claude Code, скилл появится как `/delegate-reasonix`.

Если Reasonix отказывается выполнять команды в папке, один раз выполни `reasonix trust`.

## Использование

```
/delegate-reasonix Добавь флаг --json в команду export и покрой его тестами
```

Или просто одобри план, и Claude будет отдавать Reasonix фазы по очереди.

Модель меняется в `SKILL.md`, параметр `--model deepseek-pro`.

## Безопасность

- Reasonix запускается с `--yolo`, без подтверждений. При этом песочница, сетевые правила и запреты
  самого Reasonix продолжают действовать, а контрольный коммит позволяет откатить любой запуск.
- Скилл никогда не пушит и спрашивает перед запуском в репозитории с remote.
